VERDICT ON THE DIAGNOSIS

- **The starvation → reconnect → repetition → retention mechanism is credible; dominant CPU cost and exact stall durations remain unproven.** Static code cannot establish the server’s timeout setting, a 60 MB retention increment, or which operation consumed today’s gaps.
- **Water can starve I/O:** `clears()` loops synchronously through cuts, calls the full guard before stand rejection, and can `continue` without any await. Deadline/step checks occur *after* those skips; `clearMax` counts attempted digs, not evaluated cuts (`bots/src/buildrun.mjs:953–984`). The configured limit of 24 therefore does not bound 62 unreachable cuts (`bots/src/boardwalk.mjs:28`).
- **Forest can starve I/O:** foreign-cell retries await `digNamed()`, whose `no_stand` return resolves immediately; that await only schedules a microtask. Each retry can rebuild the synchronous reachable-node search (`bots/src/buildrun.mjs:536,626–628,1101–1127,1163,1195`). Forest uses this runner (`bots/src/skills.mjs:28187–28188`).
- Forest siting also has synchronous grid preprocessing and nested tier/size/axis/location searches (`bots/src/forest.mjs:364–405`). Normal `forestFell` completion includes a real 300 ms timer yield, but its early `no_stand`/unknown-guard returns bypass it (`bots/src/skills.mjs:27979–27990`).
- **Country already yields between bands, not within them:** the `setImmediate` at entry cannot interrupt synchronous road reachability, band-tree/terrain surveys, rough-ground work, or planting scans (`bots/src/skills.mjs:26874–26881`; `bots/src/tidy.mjs:1625–1643,1674–1688`; `bots/src/country.mjs:242–269`). Awaiting this synchronous `siteStage` branch does not service sockets.

MISSED CAUSES

- Full-history reads are a strong water-path suspect, **not proven dominant everywhere**: each guard reads every project and rebuilds its cell Set; `alsoDone` adds periodic repeats (`bots/src/skills.mjs:26653–26685,26748–26751`). Using the report’s measurement, 62 × 663 ms is already about 41 seconds, before geometry.
- Geometry is distinct: `digStand` searches a local 11×11 neighborhood, whereas `nodesFor` runs the much larger synchronous `walkFrom` flood-fill; foreign retries reconstruct it (`bots/src/buildrun.mjs:416–427,536,626`; `bots/src/buildsite.mjs:377–445`). Placement searches additionally repeat support/stand tests (`bots/src/buildsite.mjs:481–505`; `bots/src/buildrun.mjs:1310`).
- Pathfinder planning also runs synchronously before waiting: `getPathFromTo().next()` uses a nominal 150 ms slice and can be invoked repeatedly by corner planning. Successful movement can yield; immediate failures need not (`bots/src/buildbot.mjs:30,275–315`). No profile supports calling it bigger than record reads.
- Other synchronous work: whole bridge-file reads before slicing to 4,000 lines; whole climb logs before filtering by age; `recordChain` rereads history for park discovery; intent logs and lease fsyncs (`bots/src/skills.mjs:18521–18524,26159`; `bots/src/buildproj.mjs:149–163,526–533,554–568,114–116,255`).
- The listing cache caches **names**, not contents; writes, recent directory mtimes and event-loop turns invalidate reuse. Fleet churn can reduce its benefit (`bots/src/buildproj.mjs:83–107`). `townDir()` itself only constructs a path (`bots/src/skills.mjs:4034`; `bots/src/worldfacts.mjs:548–550`).
- Reconnect loses `bw3At`, `bw3Given`, `bw3Stands`; `forestSkip`, `forestFails`, `forestStands`, `forestIdleUntil`; and lane scheduling `gkCountryAt` (`bots/src/index.mjs:191`; `bots/src/skills.mjs:26670,26690,26747,27910,28002,28135–28138,28187,27133–27150`).
- Adjacent retry state also resets: `tidyGiven`, `tidyStands`, `farmSkip`, `farmFails`, and `shopUnknown` (`bots/src/skills.mjs:27250,27462,27695,27754,28182`). The report incorrectly identifies **farmSkip** as the forest map. Per-visit `tries` resets even without reconnect (`bots/src/buildrun.mjs:483`).

LEAKS

- **Certain recurring roots:** `memTimer` retains `runner → bot`; the unnamed position interval retains `bot`, `runner`, and `posSamples`. Neither is cleared on `end`; `unref()` does not release references (`bots/src/index.mjs:270–282,1080–1116,1590–1609`; `bots/src/runner.mjs:31`).
- **Conditional process listener:** every enabled air trace installs `process.once('exit', stopTrace)` without end cleanup; its closure retains bot/client callbacks and the output stream (`bots/src/index.mjs:294–300`; `bots/src/air-trace.mjs:80–89,104–113`).
- **Viewer:** the call site neither stores a disposer nor closes/rebinds the viewer on end; a surviving viewer can retain its original bot/world. Only the temporary probe is explicitly closed (`bots/src/index.mjs:1457–1471,1590–1609`). Installed dependency sources are absent here, so internal viewer timers/listeners/server ownership cannot be enumerated honestly.
- The reconnect timeout intentionally survives end and retains `connect`, not an explicitly captured old bot; the probe callback can also finish after end because it has no connection-liveness check (`bots/src/index.mjs:1462–1471,1609`).
- **The “shared end emitter” claim is unsupported:** a single fresh bot already receives more than ten cleanup listeners, sufficient to trigger the warning (`bots/src/index.mjs:342,348,373,398,589,632,684,710,1250,1324,1354`). Bot-local listener cycles alone are not independent GC roots. Peak/start timers already have cleanup (`bots/src/index.mjs:1492,1593`).

RECOMMENDED FIX (ranked)

1. **D — lifecycle cleanup:** give each connection one idempotent disposer registry. Clear both leaked intervals, stop/remove the trace exit hook, and own viewer shutdown/rebinding explicitly; guard late probe callbacks. Abort connection-owned work before allowing another connection’s work. Target `bots/src/index.mjs:182,270,1081,1457,1590`.
2. **B — bounded cooperative work:** put elapsed-time `setImmediate` checkpoints plus abort/deadline checks **before skip paths** in clears and segment loops (`bots/src/buildrun.mjs:953,1082,1101`). Preserve attempt-count semantics separately. Chunk large flood-fills and country/forest scans too; an outer checkpoint cannot interrupt one oversized synchronous operation (`bots/src/buildsite.mjs:430`; `bots/src/forest.mjs:374–399`; `bots/src/country.mjs:242`).
3. **C — process retry memory:** retain the listed scheduling/failure maps in an allowlisted object scoped by bot, world, home and record identity. Stamp attempts before execution, preserve expiry, bound maps, and reject writes from ended connections. Do not retain bot/world objects, acknowledgements, leases or sockets. Existing water stamping is correctly before the await (`bots/src/skills.mjs:27150–27151`).
4. **A — verified-generation cache:** valuable fleet-wide, but a larger correctness/memory change. Share one verification engine between `recordHead` and `recordChain`; freshly discover generations, validate metadata, reuse immutable parsed/hash results, and replay ascending chain acceptance whenever membership/content changes (`bots/src/buildproj.mjs:130–163`).
5. **E — forest progress remedy:** second-piece work. Tree waiver counters do not currently handle the runner’s foreign-cell failures (`bots/src/skills.mjs:28138–28140,28187`; `bots/src/buildrun.mjs:1195`). Extract failure classification and implement a bounded alternate-stand/access or safe replanning remedy; do not merely increment a tree waiver map.
- **Smallest first reviewable piece:** D + targeted B + C, with lifecycle/starvation/reconnect tests. This breaks retention and immediate repetition while addressing the demonstrated skip-loop starvation. Include chunking wherever one operation exceeds the work budget; leave A and E for piece two. Preventing *every* observed timeout cannot be promised without profiling.

RISKS

- **Cache soundness:** `(size, mtimeNs, ino)` is conditionally sound for this publication protocol, not proof against arbitrary modification. Records are fully written/fsynced to a temporary file, atomically hard-linked to a new generation, then the temporary name is removed; this writer never rewrites published generations (`bots/src/buildproj.mjs:178–187`). Pool pruning excludes records; slot “renewal” creates a new **lease** generation (`bots/src/buildproj.mjs:615–627,255,276–278`).
- Validate stats around reads; never reuse racy/error entries; invalidate missing/replaced ancestors and preserve every rejection. Metadata-preserving rewrites/inode reuse can defeat the tuple outside the immutable-writer contract. Bound cache memory and prevent callers mutating cached records—80 processes amplify retained snapshots.
- **BLOCKER:** no max-generation-only cache, cached-success fallback on read error, dropped `gen`/root/`prev`/`prevSha` checks, or ignored rejected generations (`bots/src/buildproj.mjs:132–145`; `bots/src/skills.mjs:26660`).
- **BLOCKER:** never substitute the two-second `alsoDone` snapshot for the fresh post-walk dig guard, or insert a yield after final safety/fence checks and before sending (`bots/src/skills.mjs:26748–26751`; `bots/src/buildrun.mjs:635–639,585–605`).
- **BLOCKER:** no world edits, timeout increases as the remedy, or permanent refusal without a bot-performable recovery action. Yielding changes world freshness: discard/revalidate geometry after a pause before acting.
