## What the project is
A private fleet of 80 mineflayer bots on 16 Paper 1.21.8 survival worlds (Peaceful), one identical seed, each bot driven by a small local LLM (qwen-class, 7B–27B on local GPUs) on a ~30-s decision tick over a skill library (gather, craft, smelt, mine, explore, goto, deposit, home ...), a reflex layer (air, danger block, entombed, marooned, livelock, the "recovery ladder" of escape rungs), and a deterministic craft/milestone ladder. Started 5 Aug 2026 (576 commits, 43 source files / 24,303 lines, 164 test files). Owner's standing rules: NO cheats — no teleport, no /give, no world edits outside a sandbox [CORRECTION 17 Sep: the worlds run keepInventory=true and doImmediateRespawn=true, set at provisioning for the retired memory experiment; deaths cost time, not items]; the code must work in any Minecraft world; every change ships through a pre-registered two-pool canary read as difference-in-differences under calibrated gates, with independent Claude + ChatGPT review before building. Instrumentation: every decision, reflex and outcome is a typed telemetry row (position, inventory, cause); Elasticsearch archive; a sandbox rig that captures a live trap over RCON and replays it control-vs-candidate.
The research question changed on 4 Sep from a memory-sharing experiment (retired: the arms measured world drift and exposure) to a foundation/reliability program (13 Sep): "an unreliable autonomous colony" must survive, move, gather, keep tools and return stock, unattended.
