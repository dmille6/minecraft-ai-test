## How to restart a piece
1. `qm start <vmid>` on pve1 (ELK 109 first if analysis is needed: ES on :9200, Grafana on :80).
2. On the VM, restore the crons: `crontab ~/frozen-1122/crontab-mike.txt` (and `sudo crontab ~/frozen-1122/crontab-root.txt`).
3. Re-enable timers: `xargs -r sudo systemctl enable --now < ~/frozen-1122/timers.txt`.
4. Re-enable units: `xargs -r sudo systemctl enable < ~/frozen-1122/enabled-units.txt`, then start Paper before bots
   (bots staggered 12 s apart).
5. Mac: `launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.mcai.<name>.plist`.
6. 5080: Ollama reloads qwen2.5 on the first request.

**For analysis only** (e.g. ELK data for the new project's benchmark), start just VM 109 and leave everything else frozen.
